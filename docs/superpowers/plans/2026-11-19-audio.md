# Zvuk a hudba: implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nahrané fantasy zvuky (vlastní rodina pro každého hrdinu), hudba s prolínáním podle stavu běhu a panel Nastavení místo dnešních syntetizovaných tónů.

**Architecture:** Zvuky a hudba jsou data: `design/audio.yaml` → `npm run audio:build` → `data/generated/audio.json` (zod schéma, kontrola pokrytí proti schopnostem, hrdinům a nepřátelům). V klientu převádí `SoundView` události simulace na cue přes data, `AudioEngine` je hraje přes sběrnice s variací, limitem hlasů a stereem, `MusicDirector` (čistá logika) vybírá stopu a `MusicPlayer` prolíná dva `<audio>` prvky. Soubory vyrábí `npm run audio:encode` (ffmpeg → Opus) ze zdrojů, které stáhne Petr. Simulace se nemění.

**Tech Stack:** TypeScript, Web Audio API, HTMLAudioElement, zod, yaml, ffmpeg (libopus), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-19-audio-design.md`

## Global Constraints

- Simulace (`sim/`) se nemění; otisky determinismu a výstup `sim:run` zůstávají stejné. Událost `Hit` už nese `u` = zdroj (0 útok, 1 kouzlo, 2 summon) a `v` = slot kouzla (`sim/combat.ts`).
- Licence: CC0 přednostně; CC-BY jen tam, kde CC0 chybí, vždy s řádkem v `assets/LICENSES.md` (autor, licence, odkaz, datum, sha256 souboru v `assets/`). Nic z Warcraftu ani Blizzardu.
- Zdroje v `audio-source/` (v `.gitignore`, nedůvěryhodná data: nic odtud nespouštět); do repa jen `assets/audio/sfx/*.ogg` a `assets/audio/music/*.ogg`.
- Formát: Opus v `.ogg`; efekty mono 64 kb/s, hudba stereo 96 kb/s.
- Rozpočet: efekty celkem ≤ 3 MB, hudba celkem ≤ 15 MB.
- Variace: rozptyl výšky výchozí ±6 % (`pitchSpread: 0.06`), hlasitosti ±2 dB (`gainSpreadDb: 2`).
- Limit hlasů: celkem 32; výchozí na cue 4; smrti a zásahy nepřátel 6.
- Prolínání hudby 1,5 s; ztišení při zastavené hře na 0,35 s low-pass 900 Hz; ztišení na 0,5 po dobu 2,5 s při `BossSpawn` a `RushWarning`.
- Tep při nízkém hp: zapne se pod 25 % max hp, vypne nad 30 %, úder každých 0,9 s, jen ve stavu `playing`.
- Nastavení: celková hlasitost, hudba, efekty (0–100 %), třesení obrazu, čísla poškození; klávesa **O** v běhu, M dál ztlumí vše; uloženo v `localStorage`; texty EN a CS.
- Pravidla `AGENTS.md`: kód a komentáře anglicky, malé soubory s jednou rolí, Conventional Commits, `npm run check` před každým commitem, přesné verze závislostí. UI tmavé modrošedé, žádná oranžová.

## Review Focus

1. **Zvuk před prvním kliknutím:** události před `enable()` jsou tiché a bez chyb; menu stopa začne až po prvním kliknutí (Task 4, test `plays nothing before enable`).
2. **Soubor se nenačte (404, chyba dekódování):** cue spadne na syntézu (`synth`), v konzoli jedna hláška na cue, hra běží (Task 4, test `falls back to synth once per cue`).
3. **150 smrtí v jednom kroku:** zazní nejvýš limit cue, celkem nejvýš 32 hlasů, priorita hrdiny a varování vyhraje (Task 3, test `caps a burst of 200 starts`).
4. **Návrat do menu nebo restart uprostřed bosse:** hudba přejde na menu stopu, tep a ztišení skončí (Task 5, test `menu wins over everything`; Task 6, test `stops the pulse when the run is not playing`).
5. **`localStorage` nedostupné nebo poškozené:** výchozí nastavení, žádná výjimka; hlasitost 0 ztiší i hudební prvek (Task 7, testy `falls back to defaults` a `clamps bad values`).

**Interfaces:**
- Consumes: `Cue` (Task 2)
- Produces:
  - `vary(cue: Cue, rand: () => number): { file: string | null; rate: number; gain: number }` — `file` je náhodná varianta (`null` pro cue jen se syntézou), `rate = 1 + (2r − 1) · pitchSpread`, `gain` lineární z `gainDb ± gainSpreadDb`.
  - `class VoiceLimiter { constructor(maxTotal = 32); start(cueId: string, maxVoices: number, priority: number, now: number, seconds: number): { ok: boolean; steal: number | null; id: number }; end(id: number): void }` — hlasy po `now ≥ konec` se uvolní samy; při plném celkovém stropu ukradne nejstarší hlas s nižší prioritou (vrátí jeho `id` ve `steal`), jinak `ok: false`.
  - `panFromNdc(ndcX: number, ndcY: number): { pan: number; gain: number }` — `pan = clamp(ndcX · 0.7, −0.7, 0.7)`, mimo obrazovku (`|ndcX| > 1` nebo `|ndcY| > 1`) `gain` 0.6, jinak 1.

**Interfaces:**

- Produces:
  - `interface Volumes { master: number; music: number; sfx: number }` (0..1)
  - `class AudioEngine { constructor(data: AudioData, baseUrl: string, makeContext?: () => AudioContext); enable(): void; preload(): Promise<void>; play(cueId: string, opts?: { pan?: number; gain?: number }): void; setVolumes(v: Volumes): void; setMuted(muted: boolean): void; get context(): AudioContext | null; get musicInput(): AudioNode | null }`
  - Graf: `master` ← `musicBus` (gain + low-pass pro ztišení) a `sfxBus` (gain → `DynamicsCompressorNode` threshold −14 dB, ratio 6) a `uiBus` (gain, bez kompresoru, `category: "ui"` jde sem; hlasitost efektů platí pro `sfx` i `ui`).
