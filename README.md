# Defense Webgame

A browser survivors-like game built with TypeScript, Three.js and Vite. It is a clean-room remake of a Warcraft III map: no map data or texts are used.

Design specification: [docs/superpowers/specs/2026-11-04-defense-webgame-design.md](docs/superpowers/specs/2026-11-04-defense-webgame-design.md)

## Commands
- `npm run dev` - dev server
- `npm run check` - typecheck and tests
- `npm run build` - production build
- `npm run e2e` - end-to-end tests
- `npm run map:extract` - local map extraction (untracked output)
- `npm run data:build` - build game data

See [AGENTS.md](AGENTS.md) for the project rules.
